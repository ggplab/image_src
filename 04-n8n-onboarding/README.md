# 04 · n8n 온보딩 가이드

n8n을 처음 쓰는 분을 위한 연결·설정 가이드입니다. 외부 서비스 연결(credential), 커뮤니티 노드 설치, API 키 개념을 화면을 보며 그대로 따라 할 수 있게 정리합니다.

> 노코드 관점: 코딩 없이 화면 클릭만으로 진행합니다.

## 목차

| # | 문서 | 내용 | 상태 |
|---|---|---|---|
| 01 | [Microsoft 365 연결하기](01-microsoft-365-setup.md) | Outlook · Teams · OneDrive를 n8n에 연결 (Entra 앱 등록부터 검증까지) | ✅ |
| 02 | 커뮤니티 노드 설치하기 | n8n에 없는 노드(예: Upstage)를 설치하고 확인하기 | 작성 예정 |
| 03 | credential과 API 키 기초 | "자격증명"이 뭔지, API 키는 어디서 받는지, OAuth는 왜 필요한지 | 작성 예정 |

## 읽는 순서 추천

- 외부 서비스 연결이 처음이면 → **03 기초**부터
- 지금 당장 Microsoft 연결이 급하면 → 바로 **01**
- 원하는 노드가 목록에 없으면 → **02**
