# 커뮤니티 노드 설치하기 (예: Upstage)

n8n에 기본 제공되지 않는 노드는 "커뮤니티 노드"로 추가할 수 있습니다. 이 문서는 화면에서 클릭만으로 커뮤니티 노드를 설치하고 확인하는 방법을, Upstage 노드를 예로 정리합니다.

> **기준일: 2026-06-19** · n8n 2.17.x 기준 (셀프호스팅)
> 화면 메뉴가 문서와 다르면 공식 문서를 1순위로 보세요.
> - n8n 공식: [커뮤니티 노드 설치(GUI)](https://docs.n8n.io/integrations/community-nodes/installation/gui-install/) · [커뮤니티 노드 리스크](https://docs.n8n.io/integrations/community-nodes/risks/)

---

## 0. 커뮤니티 노드란

n8n에는 수백 개의 노드가 기본 내장되어 있지만, 모든 서비스를 다 담지는 못합니다. 커뮤니티 노드는 외부 개발자가 npm 패키지로 만들어 공개한 노드로, 내 n8n에 추가로 설치해 쓰는 것입니다. 예를 들어 Upstage(문서 OCR·문서 파싱 등) 노드는 `n8n-nodes-upstage` 라는 패키지로 제공됩니다.

> 패키지 이름은 보통 `n8n-nodes-`로 시작합니다.

---

## 1. 시작 전 확인

| 확인 | 내용 |
|---|---|
| 권한 | 셀프호스팅 n8n에서는 **Owner 또는 Admin 역할**만 커뮤니티 노드를 설치할 수 있습니다 |
| 설치 환경 | 이 문서는 **셀프호스팅** 기준입니다. n8n Cloud는 "검증된 커뮤니티 노드(Verified)"만 노드 패널에서 바로 추가할 수 있습니다 |
| 패키지 이름 | 설치할 npm 패키지 이름을 미리 확인합니다 (예: `n8n-nodes-upstage`) |

> **보안 먼저 읽기**: 커뮤니티 노드는 신뢰할 수 있는 패키지만 설치하세요. 이유는 §4에 있습니다.

---

## 2. 설치 절차

> **원칙(잘 안 바뀜)**: 설정 > 커뮤니티 노드 > 설치 > 패키지 이름 입력 > 리스크 동의 > 설치.

1. n8n 왼쪽 아래 **설정(Settings)** 으로 들어갑니다.
2. **커뮤니티 노드(Community Nodes)** 메뉴를 엽니다.
3. **설치(Install)** 버튼을 누릅니다.
4. **npm 패키지 이름** 칸에 설치할 패키지를 입력합니다.
   - 최신 버전: `n8n-nodes-upstage`
   - 특정 버전: `n8n-nodes-upstage@0.4.1`
   - 베타 등 태그: `n8n-nodes-upstage@beta`
5. 리스크 동의 체크박스에 표시합니다.
   - 문구: **"I understand the risks of installing unverified code from a public source."** (공개 출처의 미검증 코드를 설치하는 위험을 이해합니다.)
6. **설치(Install)** 를 누릅니다.
7. 설치가 끝나면 커뮤니티 노드 목록 화면으로 돌아오고, 방금 설치한 패키지가 목록에 보입니다.

---

## 3. 설치 확인하고 사용하기

1. 워크플로 편집 화면으로 가서 노드 추가(+) 패널을 엽니다.
2. 검색창에 `Upstage` 를 입력합니다.
3. 설치한 노드가 검색 결과에 나타나면 성공입니다. 노드를 추가해 사용하면 됩니다.

> 노드가 안 보이면 브라우저를 새로고침하거나, 셀프호스팅이라면 n8n을 한 번 재시작한 뒤 다시 확인하세요.

> **셀프호스팅 영속성 참고**: 설치한 커뮤니티 노드는 n8n 데이터 폴더(`.n8n`)에 저장됩니다. Docker로 운영한다면 이 폴더가 호스트 볼륨에 연결되어 있어야 컨테이너를 다시 만들어도 노드가 유지됩니다.

---

## 4. 보안 주의 (설치 전 꼭 읽기)

커뮤니티 노드는 외부 코드입니다. n8n 공식 문서가 안내하는 위험은 다음과 같습니다.

| 위험 | 내용 |
|---|---|
| 시스템 접근 | 커뮤니티 노드는 **n8n이 돌아가는 컴퓨터에 완전한 접근 권한**을 가질 수 있고, 악의적 동작을 포함해 무엇이든 할 수 있습니다 |
| 데이터 접근 | 워크플로에서 다루는 **데이터에 접근**할 수 있습니다 (민감정보 노출 가능) |
| 호환성 | 개발자가 업데이트하면서 **이전 기능이 깨질 수 있습니다** |
| 검증 여부 | n8n이 보안 요건을 확인한 "검증된 노드"가 있고, 그 외 npm 공개 패키지는 미검증 코드입니다 |

**실무 원칙**

- 제공자가 분명하고 널리 쓰이는 패키지만 설치합니다 (예: 서비스 공식 제공 노드).
- 의심스러운 노드는 설치하지 말고, 발견 시 n8n에 신고합니다 (`security@n8n.io`).
- 필요 없으면 셀프호스팅 설정에서 커뮤니티 노드 기능 자체를 끌 수도 있습니다.

---

## 5. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 설치 메뉴가 없음/회색 | Owner·Admin 권한이 아님 | 관리자 계정으로 로그인하거나 관리자에게 요청 |
| 패키지를 못 찾음 | 패키지 이름 오타 또는 비공개 패키지 | npm에서 정확한 이름 확인 후 다시 입력 |
| 설치는 됐는데 노드가 안 보임 | 캐시/세션 | 브라우저 새로고침, 셀프호스팅이면 n8n 재시작 |
| 일부 패키지가 차단됨 | n8n 차단 목록(blocklist)에 포함 | 다른 패키지로 대체하거나 공식 문서 확인 |
